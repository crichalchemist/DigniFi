# Forms step 3h4, the line 43 AI polish: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Under each line 43 explanation box, a filer can ask an AI service (Anthropic, `claude-sonnet-5-5` by default) to rewrite their own explanation more clearly; the first press asks consent that names the vendor and its retention; the browser sends the box's trimmed text alone, once, with no retry; the server refuses a text holding the filer's own identifiers or a prohibited phrase before any send, sends the rest with one fixed system prompt, checks the reply (printable whole, no prohibited phrase, no added or dropped figure, dated month or name, no added legal conclusion, not gutted) and returns it or one plain sentence; the page shows the rewrite beside what was sent, editable, and only "Use this rewrite" puts it in the box, keeping the filer's own words beside it as `original_explanation`, which "Put my own words back" restores; Continue saves both through the means-test PUT and its fit checks; nothing the service wrote prints without that approval, no filer text or model text reaches a log, the audit trail or a response body beyond the rewrite itself, and every failure leaves the guided draft as it was.

**Architecture:**

- **Settings** (`config/settings/base.py`, `production.py`, `test.py`): `AI_POLISH_PROVIDER`, `AI_POLISH_API_KEY`, `AI_POLISH_MODEL`, empty by default and pinned empty under test; a `polish` throttle rate (`10/minute`) in both rate tables (`REST_FRAMEWORK["DEFAULT_THROTTLE_RATES"]`, a key of the `REST_FRAMEWORK` dict, not a Django setting of its own: T1-D1); the `anthropic`, `httpx`, `httpx2` and `httpcore2` loggers pinned at `WARNING`, `propagate: False` (R3, R20; `httpx2` and `httpcore2` are plan additions, Corrections item 2, T1-D2). `anthropic==2.9.0` pinned in `requirements/base.txt` (R1).

## Global Constraints

- **Nothing the service wrote prints, saves or shows without the filer's approval** (S:849, S:879). The polish endpoint writes nothing: no `MeansTestAnswers`, no `lock_session`, no `reopen()`, no `WRITES` entry. An unapproved rewrite lives only in `Line43`'s `pending` (R12). The invariant test (Task 7) is the proof.
- **Only the explanation goes out, and the filer's identifiers never do** (S:861, R7). The request body is `{"explanation": "<trimmed text>"}` and nothing else; `PolishRequestSerializer` refuses any other key by name with `NOT_A_MEANS_ANSWER` (`means_test.py:72`).
