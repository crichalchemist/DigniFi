# Forms step 3h3, Form 122A-2 prints: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An above-median filer's Form 122A-2 prints complete from the one calculator, every one of its 198 widgets bound to its line or blank on purpose, rows past the form's boxes and every line 43 explanation on attached sheets, and Form 122A-1 prints again with box 2; the gate's last step refuses only for a page gap, a missing table or a line the calculator can't work out; Mark as Filed ties the pair on the server and in the card; DIG-513's eight residuals, DIG-514's line 3 cap and DIG-515's button names land first; Priya reaches the dashboard and Generate All makes 16 forms.

**Architecture:**

- **Calculator** (`apps/eligibility/means_lines.py`, pure): `MeansInputs` gains `spouse_cmi` and `line_43_rows`; `ROW_KEYS` gains `"43"`; line 3 above the spouse's Column B is `MISSING` (R7); a reached line 43 Yes with an unfinished circumstance is `MISSING` (R4); `line_43_rows_to_print(lines)` is the one test the pointers and the sheet read; `missing_line(lines)` is one `any` over `lines.lines` (R8).
- **Holder** (`apps/eligibility/means_inputs.py`): `one_read_of_means()` and `means_lines_for(session)` hold one `work_out` per resolve, keyed by `session.pk`, in the `exemption_items.py:178-189` shape (R3).
- **Cells** (`apps/forms/services/means_cells.py`, new, pure): `means_value(binding, lines)` is the whole `means.` reader table (R2): a `MeansLines` in, `str | list[str]` out, `MISSING`/`SKIPPED` → `""`, never `"0.00"`; the only place a `means.` spelling is decoded.
- **Engine** (`apps/forms/schema.py`, `fill_resolver.py`): `means.` joins the namespaces, `_LIST_BINDING` and `_STATEMENT_BINDING` (R5); `resolve_binding` gains one branch; `resolve_parts` adds `one_read_of_means()` to its `with`; `binding_fix` branches by attribute (R6); `tests/pdf_readback.py` gains `read_sheet_part` (R19).
- **Schema** (`data/forms/field_index/tools/build_form_122a2.py`, new): writes `form_122a2.json` (130 fields, six slot groups, one statement group, 178 widgets bound) and every `form_122a2` row of `step2_verification.json` (R1, R14, R15, R25); the oracle tiers judge it below the gate before the gate lifts.
- **Gate** (`apps/forms/registry.py`): 122A-2's `requires()` is a missing table, the Income step's gap, the page's first gap, then `missing_line` with `FORM_122A2_LINE_MISSING` (R8, R9); `FORM_122A2_CANT_PRINT_YET` goes with every stand-in (R24).
- **Pair** (`apps/forms/views.py`): `POST /api/forms/mark_pair_filed/` marks both or neither in one locked transaction (R10); the per-row Mark as Filed refuses one form of the pair with `MEANS_PAIR_REFUSAL` (R11); `_generate_and_persist`'s save is conditional on the row not being filed (R11); the action joins `WRITES` (R12).
- **Dashboard** (`FormCard.tsx`, `FormDashboard.tsx`): an in-card confirm for the pair, the partner's notice before marking alone, `api.forms.markPairFiled` (R13).
- **The page's fixes** (DIG-513, R26; DIG-514, R7; DIG-515, R27) land in Tasks 1 and 3, before the gate reads from the page.

**Tech Stack:** Django 5.0, DRF, `encrypted-model-fields` (Fernet), pypdf/PyMuPDF form engine, pytest-django (sqlite; Postgres for the `postgres` marker), React 19 + Vite + vitest + MSW, Playwright. No new dependency.
